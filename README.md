# GodPoemTarot

台灣籤詩、擲筊與 Rider–Waite–Smith 塔羅的純前端占卜網站。

這個專案的出發點很簡單：

**既然要做線上求籤，那就不要只做一個亂數按鈕。**

GodPoemTarot 收錄多套台灣常見籤詩，包含原始籤文、典故、白話解讀、常見問事項目與資料來源，也加入擲筊與塔羅功能。

整個網站不需要資料庫、不需要後端，下載後直接開啟 `index.html` 就能使用。

## 線上直接使用

不想下載的話，可以直接使用 GitHub Pages 版本：

https://donma.github.io/GodPoemTarot/

## 這個專案有什麼

### 擲筊

網站內建擲筊功能。

需要連續擲出三次聖筊，才會解鎖後續求籤與塔羅功能。

算不算必要不知道。

但至少比打開網站直接看到一顆抽籤按鈕有誠意。

---

### 多套台灣籤詩

GodPoemTarot 不是只放一套觀音籤。

目前整理了 8 套常見籤詩系統，共 619 首。

每首籤除了籤文本身，也盡量整理：

* 吉凶
* 籤詩典故
* 傳統解說
* 白話解讀
* 工作
* 財運
* 感情
* 婚姻
* 健康
* 考試
* 官司
* 出行
* 失物
* 家宅
* 其他常見問事項目

如果某個項目找不到足夠資料，也不會硬湊答案。

有資料就寫。

沒資料就承認沒有。

## 亂數不是 `Math.random()`

GodPoemTarot 使用瀏覽器提供的 Web Crypto API 產生亂數。

也就是：

```javascript
crypto.getRandomValues()
```

而不是單純使用：

```javascript
Math.random()
```

籤詩另外採用千次亂數聚合方式決定最終結果。

從數學上來說，它還是公平隨機。

從體感上來說，比 `Math.floor(Math.random() * 60)` 有儀式感多了。

## 籤詩資料不是隨便貼上去

這個專案除了網站本身，其實也花了不少時間整理籤詩資料。

每筆資料盡量保留：

* 原始籤文
* 傳統內容
* 籤詩故事
* 白話解讀
* 不同問題分類
* 資料來源
* 整理與審核狀態

所以 GodPoemTarot 不只是占卜網站。

它也可以作為：

* 籤詩資料整理
* 民俗研究
* 資料分析
* 中文語料
* AI / RAG
* 個人研究專案

的基礎資料來源。

---

## 關於 AI 整理內容

部分資料有使用 AI 協助整理與轉換。

但 AI 不會被當作文獻來源。

資料來源與 AI 整理內容是分開紀錄的。

簡單來說：

AI 可以幫忙整理古書。

但不能說那本古書是 AI 寫的。

---

## 資料仍在持續校對

目前籤詩內容已完成大量整理與自動檢查，但仍有部分內容處於人工複核階段。

因此專案內會區分：

* 已有資料
* AI 協助整理
* 待人工確認
* 資料不足

自動檢查通過，只代表資料格式與基本規則正常。

不代表：

```text
神明已經 Approve PR
```

## 為什麼做這個

網路上其實不缺求籤網站。

但很多網站只有：

```text
按一下
↓
抽到第 XX 籤
↓
顯示一段文字
```

GodPoemTarot 想做得稍微完整一點。

除了可以真的拿來求籤之外，也希望把台灣籤詩這些散落在各處的內容，慢慢整理成比較有結構、比較容易保存、也比較容易被後續使用的資料。

傳統籤詩本身包含了很多：

* 宗教文化
* 歷史故事
* 民間信仰
* 人生觀
* 地方文化

如果只是做成一個 Random 頁面，有點可惜。
